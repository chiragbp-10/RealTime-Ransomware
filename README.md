Developed a web-based cybersecurity solution focused on detecting and mitigating ransomware attacks using adaptive machine learning and multi-layered monitoring. 
The system allows users to securely register and log in, upload datasets, and view data previews for analysis. 
Multiple machine learning models are evaluated, and their accuracies are compared to identify the most effective algorithm for ransomware detection.

The application provides a user-friendly interface for model selection, accuracy evaluation, and result visualization, enabling informed decision-making in threat detection. 
This project enhanced my understanding of cybersecurity principles, machine learning workflows, data analysis, and full-stack application development, along with teamwork and problem-solving skills.
